# Security

This project is alpha software. Do not use it as the sole archive of important
records or assume that screen-title exclusions prevent every sensitive capture.

For a suspected vulnerability, use GitHub's **Report a vulnerability** option in
the repository Security tab when available. Do not publish personal memory data,
credentials, real transcripts or sensitive reproduction material in an issue.
If private reporting is unavailable, open a minimal issue asking for a private
contact route without disclosing exploit details or private data.

Only the current alpha receives fixes. There is no promised response time or
supported enterprise deployment model. See [Privacy](docs/PRIVACY.md) and the
[MCP boundary](docs/MCP.md) for the current data and trust model.
